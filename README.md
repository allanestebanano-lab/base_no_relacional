# Bases de Datos No Relacionales

## Descripción

Proyecto académico para implementar y documentar
cuatro prácticas de bases de datos NoSQL utilizando
Docker, MongoDB, Mongo Express, Node.js y Redis.

## Entregables

1. MongoDB y Docker: instalación, administración y persistencia.
2. Mongo Express: colecciones, documentos BSON y operaciones CRUD.
3. Node.js y MongoDB: transacciones multidocumento ACID.
4. Redis: estructuras de datos, TTL, diagnóstico y persistencia.

## Metodología

Cada entregable se desarrolla individualmente
siguiendo cinco criterios de evaluación.

Por cada criterio se documentarán:

- Objetivo técnico.
- Configuración implementada.
- Procedimiento de ejecución.
- Resultado de las pruebas.
- Evidencias visuales.
- Justificación y conclusiones.

## Herramientas

- Windows 10
- Visual Studio Code
- Docker Desktop 4.97.0
- Docker Compose 5.6.1
- MongoDB
- Mongo Express
- Node.js
- Redis

## Estado

Fase 0: preparación del entorno.
Entregables 01 al 04: pendientes de implementación.

## Regla de validación

Ningún criterio se considera aprobado hasta comprobar
su funcionamiento mediante pruebas y evidencias reales.
